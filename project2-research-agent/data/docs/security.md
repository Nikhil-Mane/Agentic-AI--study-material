# Security policy

If a company laptop or phone is lost or stolen, report it to the security team within one hour using the incident hotline. The device will be remotely wiped.

All laptops must use full-disk encryption and an automatic screen lock after five minutes.

Passwords must be stored in the approved password manager. Sharing passwords over chat or email is forbidden. Multi-factor authentication is mandatory for all company accounts.

Suspected phishing emails must be forwarded to the security mailbox and never opened or answered.
